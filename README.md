# 🧩 Лекало анонсов

**«Лекало»** — Telegram-бот для создания анонсов мероприятий по собственным шаблонам.

У каждой площадки свои правила оформления анонсов. В «Лекале» можно задать нужный формат, сохранить постоянные сведения о площадке и больше не вставлять их вручную в каждый пост.

Организатор отвечает на вопросы бота и получает готовый анонс с текстом, ссылками и фотографиями.

**[Открыть «Лекало» в Telegram](https://t.me/lekalo_app)**

## 📝 Как это работает

1. **Выбираете площадку** или свой личный шаблон.
2. **Отвечаете на вопросы:** название мероприятия, дата, время, описание и другие сведения, предусмотренные шаблоном.
3. **Получаете готовый анонс.** Его можно отредактировать, добавить фотографии и переслать в канал.

Созданные анонсы сохраняются в боте. К ним можно вернуться позже.

## 🧱 Шаблоны и кирпичики

Шаблон определяет, как будет выглядеть анонс. Кирпичики — это отдельные поля, значения которых бот запрашивает при создании поста.

Например, небольшой шаблон может выглядеть так:

```text
[название]

[дата], [время_начала]
[место]

[описание]
```

После заполнения получается:

```text
Читка пьесы

9 ноября (пн), 19:00
РанДом Культуры

Читаем пьесу по ролям. Можно
прийти послушать или самому
взять роль. Готовиться заранее
не нужно.
```

Это сокращённый пример. В настоящем анонсе сохраняются оформление текста, ссылки и другие элементы шаблона.

Кирпичики можно добавлять, удалять и переставлять местами. Так можно собрать разные шаблоны для лекций, концертов, дискуссий и других мероприятий.

## ⚙️ Что ещё умеет бот

- **Площадки.** Общий справочник с городами, адресами и ссылками. У каждой площадки свой шаблон, которым управляют её администраторы.
- **Личные шаблоны.** Можно создавать анонсы без привязки к площадке, используя собственные заготовки.
- **Дополнительные поля.** Для мероприятий, которым требуется больше сведений, можно использовать расширенный вариант шаблона.
- **Фотографии.** К анонсу можно прикрепить до десяти изображений.
- **Редактирование.** Готовый анонс можно поправить, не заполняя всё заново.

## 💻 Самостоятельный запуск

Исходный код опубликован в этом репозитории.

Бот написан на Python с использованием `python-telegram-bot`. Для хранения данных используется SQLite.

В каталоге `Poster` находятся зависимости проекта и пример файла конфигурации `.env.example`. Для самостоятельного запуска понадобится отдельный Telegram-бот и его токен.
