# Лекало анонсов

**«Лекало»** — Telegram-бот для создания анонсов мероприятий по собственным шаблонам.

Бот собирает анонс из ваших ответов, подставляет адреса, ссылки и другие сведения о площадке. Готовый пост можно отредактировать и переслать в канал.

У каждой площадки свой формат анонсов. Поэтому «Лекало» не привязано к одному шаблону: его можно переделать под свои стандарты.

**[Открыть «Лекало» в Telegram](https://t.me/lekalo_app)**

## Как это работает

Есть два способа создать анонс:

- **Для площадки.** Выбираете площадку, отвечаете на вопросы и получаете пост в её стандартном формате. Адрес и другие известные сведения подставляются автоматически.
- **По личному шаблону.** Создаёте собственный формат анонса, без привязки к площадке.

Пока вы отвечаете на вопросы, бот собирает текст. После создания можно поправить отдельные поля, изменить фотографии или дополнить анонс вручную перед публикацией.

Бот старается не засорять чат: служебные экраны обновляются, а обработанные сообщения с ответами удаляются.

## Что умеет

**Шаблоны и кирпичики**

Шаблон определяет структуру анонса. Кирпичики — это поля, значения которых бот спрашивает при создании поста.

Например, вместо `[дата]` подставляется дата мероприятия, а вместо `[описание]` — его описание.

Можно менять порядок полей, оформление текста и создавать собственные кирпичики. Шаблоны подходят для разных форматов мероприятий.

**Площадки**

В боте есть общий справочник площадок. У каждой могут быть свои адрес, ссылки и стандартный шаблон.

Администраторы управляют сведениями и шаблонами своих площадок. Остальные пользователи могут создавать по ним анонсы.

**Фотографии и редактирование**

К анонсу можно прикрепить фотографии, а после создания — изменить текст или изображения.

Готовые анонсы сохраняются в разделе «Мои анонсы».

## Запуск своей копии

Исходный код доступен в этом репозитории.

Бот написан на Python с использованием `python-telegram-bot`. Данные хранятся в SQLite.

Для самостоятельного запуска нужен токен Telegram-бота и настройка окружения. В репозитории есть пример конфигурации `.env.example`.

Отдельную инструкцию по установке и развёртыванию ещё предстоит подготовить.
